### 当前视觉的实际水平（实话）

- **浅色模式 = Qt 默认样式**，没有任何自定义。这是改版最大的空间。
- 深色模式只是一份约 25 行的 QSS：纯色块 + 1px 边框，无圆角、无层次、无阴影。

## 四、四种候选风格（差异明显，均为 QSS + QPainter 可实现）

> 四套都遵守「涨红跌绿」与离线约束。选一套后我再出具体视觉稿与配色令牌。

### A. 数据终端（Density First）— 密度与扫读优先

- **气质**：专业行情软件，冷静、克制、信息密度高。
- **配色**：中性灰阶为主（`#FAFAFA` / `#F0F1F3` / `#1A1A1A`），唯一强调色为中国红，仅用于正收益与主按钮。
- **版式**：去掉卡片阴影，改用 1px 分隔线；行高压缩到 28px；数字列等宽右对齐、单位弱化为小字灰色。
- **特征**：一屏能看到 20 条记录完整七列，不滚动。图表压扁成细长条（高 90px）。
- **适合**：想要"打开就知道赚了多少"的效率型用户。
- **代价**：观感朴素，不像"新产品"。

### B. 纸质账簿（Editorial Ledger）— 温度与信任感

- **气质**：一本装帧讲究的账本，安静、有手感。
- **配色**：米白底 `#F7F5F0`、墨黑文字 `#1F1B16`、红章色 `#A63A2E`、绿 `#456B52`；深色版为"夜读" `#14120F`。
- **版式**：衬线标题（宋体/思源宋体），表格去掉竖线只留极细横线，行距宽松，金额用较大字号。
- **特征**：4 张统计卡片改为"顶栏一行文字 + 大数字"，像账簿抬头的手写汇总。图表改为细长竖线（火柴杆图）。
- **适合**：把记账当仪式、重视"这是我自己的账"的感觉。
- **代价**：单屏信息量最小，需滚动；衬线中文字体需确认本机可用。

### C. 轻卡片工作台（Soft Card）— 现代 SaaS 观感

- **气质**：Notion / Linear 那一类，干净、呼吸感强、有层次。
- **配色**：纯白底 `#FFFFFF` + 卡片 `#FFFFFF` + 页面底 `#F7F8FA`；主色可用低饱和蓝灰 `#3B5BDB` 或墨绿；红绿只用于金额。
- **版式**：12px 圆角卡片 + 极浅投影（`QGraphicsDropShadowEffect`）；导航改为顶部胶囊标签；统计卡片大数字 + 小标签 + 涨跌色。
- **特征**：块状分区明显，留白大；表格放进圆角容器内，表头浅灰底。
- **适合**：直觉上"这软件做得挺认真"。
- **代价**：单屏信息量下降约 1/4；圆角与阴影在 QSS 里需要额外绘制，工作量最大。

### D. 深色仪表盘（Dark Dashboard）— 夜间与视觉冲击

- **气质**：默认深色，像车载仪表或交易终端。
- **配色**：底 `#141518`、卡 `#1C1E22`、分隔 `#2A2D33`；红 `#FF5A52`、绿 `#3DD68C`（深底上提亮以保证对比度）；主文案 `#E8E9EB`。
- **版式**：图表上移占据上半屏（两张图并排、各高 160px），表格下沉；数字超大（统计卡片 32px）。
- **特征**：强对比、发光感（柱顶加亮边）；浅色版为同一套结构的"日间降饱和"版本。
- **适合**：主要在晚上记账、喜欢深色的人。
- **代价**：长时间看浅色场景会刺眼；"日间版"需单独调一轮，工作量翻倍。

### 选择建议

| 如果你更在意 | 选 |
|---|---|
| 打开就能看清、不想点来点去 | **A** |
| 用起来舒服、像自己的账本 | **B** |
| 界面看起来"像样"、愿意长期用 | **C（推荐）** |
| 夜间使用、喜欢深色 | **D** |

我的倾向是 **C 的版式 + A 的表格密度**：卡片留白要够，但表格一行都不能少。这个组合最贴合"一年开十几次、每次只想快速确认收益"的实际使用方式。

## 五、改版必须遵守的工程规矩

1. **UI 层不碰 SQL、不碰业务计算**。所有数据通过 `application/*_service.py` 取；`domain/*` 不得 import PySide6。
2. **子页面发 `Signal`，由 `MainWindow` 调服务**（`ARCHITECTURE.md` 决策 10）。子页面不持有主窗口或服务引用——曾因循环引用导致对象被提前回收。
3. **测试必须继续通过**：当前 **228 项**（`.venv\Scripts\python -m pytest -q`）。改动 UI 结构时，`tests/ui/test_main_window.py` 里大量用例直接访问控件属性（如 `window.table`、`window.search_input`、`window._sort_key`），**重命名控件会连带改测试**，这是预期成本。
4. **`tests/conftest.py` 的隔离夹具不可删**：它保证测试不写用户真实注册表。
5. **改完必须同步**：`CHANGELOG.md` 记一笔、`ARCHITECTURE.md` 若动了结构补决策、`docs/已知问题.md` 若修了隐患则勾掉。
